# Abg. Martha Solano - Sitio Web Jurídico

Sitio web corporativo profesional desarrollado para la Abg. Martha Solano, especialista en derecho familiar y patrimonial. El sitio está diseñado para transmitir confianza, autoridad y elegancia, facilitando la captación de clientes locales e internacionales.

##  Características Destacadas
*   **Diseño Elegante y Corporativo:** Paleta de colores cálidos y tipografía serif (`Libre Bodoni`) que proyectan formalidad y confianza legal.
*   **Accesibilidad Web (a11y):** Implementación de enlaces de "Saltar al contenido" y etiquetas ARIA para lectores de pantalla.
*   **Formulario Inteligente de Contacto:** Sistema en JavaScript que captura los datos del cliente y genera automáticamente un mensaje estructurado para enviar por WhatsApp.
*   **Sección de Acordeón FAQ:** Preguntas frecuentes interactivas sin necesidad de frameworks externos.
*   **Optimización Móvil:** Menú hamburguesa totalmente funcional y adaptado a dispositivos táctiles.

##  Stack Tecnológico
*   **HTML5:** Etiquetas semánticas y metadatos SEO optimizados.
*   **Tailwind CSS (CDN):** Configuración personalizada del tema (`ink`, `cream`, `plum`, `gold`) y tipografía del sistema.
*   **JavaScript:** Manejo del DOM para el menú móvil, el acordeón de FAQs y la generación dinámica de los enlaces de WhatsApp.
*   **GitHub Pages:** Despliegue y configuración de dominio personalizado con certificado SSL.
